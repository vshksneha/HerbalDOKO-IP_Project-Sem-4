# 🌿 HerbalDOKO

**HerbalDOKO** is an Android application for buying, managing, and distributing herbal products.  
It features a clean **XML-based UI**, backend services in **Java**, and real-time database support via **Firebase** to ensure smooth user experience and scalability.

## ✨ Features

- 🔐 **User registration & login**  
- 🛍️ **Product listing** with categories  
- 🔎 **Search & filter** herbal products  
- 📄 **Product detail pages** with images, description, pricing  
- 🛒 **Cart & ordering** functionality  
- ⚙️ **Backend services** in Java for business logic  
- ☁️ **Real-time data storage & sync** through Firebase  
- 📱 **Responsive interface** built with XML layouts

## ⚙️ Setup & Installation

1. **Clone this repository**  
   ```bash
   git clone https://github.com/vshksneha/HerbalDOKO-IP_Project-Sem-4.git
   cd HerbalDOKO-IP_Project-Sem-4
2. **Open in Android Studio**
    Import the Android project as an existing Gradle project.

3. **Configure Firebase**
   -Create a Firebase project in Firebase Console

   - Add an Android app, get the google-services.json file.

   - Place it in /app directory (inside app/src).

   - Enable required services (Authentication, Realtime Database, etc.)

4. **Build and Run**

Gradle sync → Build → Run on emulator or physical device with Android version ≥ (your min SDK).
